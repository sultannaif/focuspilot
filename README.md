# FocusPilot

واجهة أولية عربية لمنصة إدارة الالتزام والأولوية الشخصية.

## التشغيل

لا تحتاج النسخة الأولية إلى تثبيت حزم. شغل خادم ملفات ثابت داخل المجلد، مثل:

```powershell
python -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## الحالة الحالية

- إدارة الوظائف وقيمتها الشهرية.
- إضافة المهام وربطها بالوظائف.
- ترتيب ذكي يعتمد على القيمة المالية، الاستعجال، مدة المهمة وأهميتها.
- شاشة "مهمتك الآن".
- تقييم إنجاز يومي محليًا عبر `localStorage`.

الخطوة التالية هي ربط هذه البيانات بـ Supabase Auth وPostgres بدل التخزين المحلي.
